# Inverted Pyramid AI

Governed AI answers over air-medical transport operations data (billing and revenue cycle, flight ops, finance, HR), built as inverted funnels of inference waves that feed one governed semantic pool.

**Synthetic data only**: no real patients, employees, aircraft or companies. Runs locally on DuckDB with local models; maps one-to-one onto Snowflake (Cortex Search, Cortex Analyst, Streamlit in Snowflake). See [ARCHITECTURE.md](ARCHITECTURE.md).
